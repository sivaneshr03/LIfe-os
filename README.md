## ⚡ AAS Skill Manager CLI (2,465+ Skills)

You have access to the complete **Agentic Awesome Skills** library of over **2,465 skills** across 50+ categories via the built-in CLI:

```bash
# View all installed skills
npm run skill:list

# Search across 2,465 skills by topic (e.g. react, tailwind, backend, python, ai)
npm run skill:search <keyword>

# Inspect details and description for any skill
npm run skill -- info <skill-id>

# Install any skill on demand
npm run skill -- install <skill-id>

# Remove a skill when no longer needed
npm run skill -- remove <skill-id>

# Explore all available skill categories
npm run skill:categories
